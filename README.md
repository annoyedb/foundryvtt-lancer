# Lancer System for FoundryVTT

A Foundry VTT system for the [Lancer RPG](https://massif-press.itch.io/corebook-pdf) by [Massif Press](https://massif-press.itch.io/).

## Contributing

This open source project accepts PRs from community members, at the discretion of the project maintainers. As a volunteer project, we do not have the time, effort, nor desire to spare on reviewing and managing primarily AI-generated contributions. Any such contributions will be discarded.

Some responsible usage of AI tools may be acceptable. Ideally, we request that contributors write and debug their own code (zero AI-generated code). If AI is used to generate code or text (e.g. documentation, PR/issue descriptions, etc...), the following standards must be met as a minimum.

1. AI-generated media are strictly disallowed from this project. (Images, art, audio, video, etc...)
2. AI usage for generating code or text (issues, PR description, etc...) must be disclosed. This disclosure must include the specific AI tools used, a general description of the workflow, and an estimated percentage of code/text generated by said tools.
3. The PR/issue author is a human who has spent time understanding the issue and/or the problem they intend to solve with a PR, as well as this project in general.
4. The author understands the code in their PRs and can explain it without the use of AI tools. If you cannot do this, please do not submit a PR.

Following these requirements is not a guarantee that the contribution will be accepted. Maintainers still have full discretion as they deem appropriate for the scope, quality, and health of this project.
